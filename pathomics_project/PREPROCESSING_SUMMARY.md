## 2️⃣ 전처리 문제점과 해결

### ❌ 문제 1: 22개 클래스가 너무 세분화됨
임상적으로 의미있는 5개 대분류(Tumor/Stroma/Immune/Necrosis/Other)로 통합 필요

**해결**: `meta/gtruth_codes.tsv` 원본을 직접 확인해서 정확한 22→5 매핑 테이블 작성 (추측 없이 원본 소스 기반)

### ❌ 문제 2: 이미지 크기가 통일되어 있지 않음
슬라이드마다 크기가 제각각이라 배치 학습 불가능

**해결**: 512×512 고정 크기 패치로 분할 (`extract_patches()`), 배경 위주 패치는 자동 제외

### ❌ 문제 3: 여러 기관/스캐너 출처라 염색 색감 편차 존재
같은 조직이라도 스캐너/염색 프로토콜에 따라 색이 다르게 나옴

**해결**: Macenko 염색 정규화 구현. 합성 데이터 검증 결과 서로 다른 색조의 두 이미지 간 조직 픽셀 색상 차이가 **70.06 → 2.02로 약 97% 감소**. 이후 실제 BCSS 151장 전체로 재검증 완료(에러 0건, `visualize_patches.py`로 육안 정렬 확인).

### ❌ 문제 4: 패치 단위 분할 시 데이터 누수 위험
같은 환자의 패치가 train/test에 동시에 들어가면 성능이 부풀려짐

**해결**: 패치가 아니라 **환자(TCGA case ID) 단위로 먼저 분할**한 뒤, 그 안에서 패치 추출

### ❌ 문제 6: 팀 기획서 공식 규약과 불일치 (2026-07-14 발견 및 수정)
초기 구현이 기획서 규약과 두 군데 어긋났음:
- 클래스 매핑: `lymphatics`(림프관)를 immune에 잘못 포함 → 기획서 규약(lymphocytes/plasma cells/other immune infiltrates만 inflammatory)에 맞춰 `other`로 이동
- 분할 방식: 무작위 환자 분할 사용 → 기획서가 요구하는 **6개 기관(OL, LL, E2, EW, GM, S3) held-out 분할**로 교체

**해결**: `consolidate_mask()` 매핑 테이블 수정, `split_by_case()` → `split_by_institution()`으로 교체. 재실행하여 151명 전체에서 6개 기관 전부 확인됨 (아래 3️⃣ 참고)

### ❌ 문제 5: 손상되거나 불완전한 이미지/마스크 처리
- 이미지-마스크 파일이 서로 짝이 안 맞는 경우
- 이미지와 마스크의 해상도가 다른 경우 (파일 손상 가능성)
- 마스크가 전부 배경/제외 클래스인 경우 (조직이 없는 슬라이드)
- 이미지 로드 자체가 실패하는 경우

**해결**: `preprocess_split()`에 4중 방어 로직 추가
1. `collect_pairs()`: 이미지-마스크 파일명 매칭 확인, 짝 안 맞는 파일은 제외 + 경고 로그
2. 이미지/마스크 로드 실패 시 예외 처리 후 해당 슬라이드 스킵 (전체 파이프라인 중단 방지)
3. 이미지-마스크 shape 불일치 시 조용히 잘못된 패치를 만들지 않고 명시적으로 스킵
4. 마스크가 전부 배경(class 0)인 경우 스킵 (학습에 기여 못하는 빈 데이터 배제)

## 3️⃣ 전처리 파이프라인 (5단계)

| Step | 내용 | 상태 |
|------|------|:---:|
| 1 | 이미지-마스크 페어 수집 및 매칭 검증 | ✅ 실데이터 151쌍 전부 매칭 |
| 2 | 클래스 분포 샘플 확인 | ✅ 실데이터 검증 |
| 3 | **기관 단위(held-out) train/calibration/test 분할** | ✅ 실데이터: 151명 -> train 91 / calibration 15 / test 45 |
| 4 | 512×512 패치 분할 + 배경 필터링 | ✅ 실데이터 검증 |
| 5 | Macenko 염색 정규화 + 픽셀 정규화 | ✅ 실데이터 검증 |

### 🎉 전체 파이프라인 실행 결과 (2026-07-14, 기획서 규약 반영 후 재실행, 151장 전량)

| 분할 | 슬라이드 성공 | 슬라이드 실패 | 생성된 패치 수 |
|------|:---:|:---:|:---:|
| train | 91 | 0 | 4,500 |
| calibration | 15 | 0 | 777 |
| test | 45 | 0 | 2,156 |
| **합계** | **151** | **0** | **7,433** |

실패 0건 — 파일 로드 실패, 이미지-마스크 크기 불일치, 전부 배경인 슬라이드 등 방어 로직에 걸린 케이스가 하나도 없었습니다.

**기관 커버리지**: 기획서 지정 6개 held-out 기관(OL, LL, E2, EW, GM, S3)이 151명 안에 **전부 존재함**을 확인 (경고 없이 전체 발견). Test셋이 45명(약 30%)으로 무작위 15%보다 크게 나온 건, 특정 기관에 환자가 몰려있는 실제 분포를 그대로 반영한 것이라 정상입니다.

## 4️⃣ 최종 클래스 매핑 (22개 → 5개)

| 대분류 | 포함 원본 클래스 |
|--------|-----------------|
| **Tumor** | tumor, angioinvasion, dcis |
| **Stroma** | stroma, normal_acinus_or_duct |
| **Immune (inflammatory)** | lymphocytic_infiltrate, plasma_cells, other_immune_infiltrate — **기획서 공식 규약 그대로** |
| **Necrosis** | necrosis_or_debris |
| **Other** | glandular_secretions, blood, metaplasia_NOS, fat, mucoid_material, **lymphatics**, nerve, skin_adnexa, blood_vessel, other |
| *(배경/제외, don't-care)* | outside_roi, exclude, undetermined |

> ⚠️ 2026-07-14 수정: `lymphatics`(림프관)는 원래 Immune에 있었으나, 기획서 규약이 명시한 inflammatory 3종(lymphocytes/plasma cells/other immune infiltrates)에 없어서 Other로 이동함. TIL 비율(면역/기질 면적비) 계산의 정확도에 직결되는 수정.

### 이미지-마스크 정렬 육안 검증 (완료)

`visualize_patches.py`로 train 패치 6개를 무작위로 뽑아 [원본 이미지 | 색칠된 마스크 | 겹침] 형태로 시각화하여 확인함 (기관 분할 수정 전 버전 기준. 이미지-마스크 픽셀 정렬 자체는 클래스 매핑/분할 방식과 무관하므로 이 검증 결과는 재실행 후에도 유효함).

- ✅ 원본 이미지가 실제 H&E 염색 조직(세포핵 패턴)으로 정상 표시됨 → 역정규화 로직 정상
- ✅ 마스크 색상 영역이 겹침 이미지에서 **픽셀 단위로 정확히 같은 위치**에 표시됨 → 이미지-마스크 밀림/오정렬 버그 없음
- ✅ 색 경계가 조직의 실제 세포 밀도 변화와 대체로 일치하는 패턴 관찰 (예: immune 클래스 영역이 세포가 빽빽한 부분과 겹침)
- ⚠️ 클래스 라벨 자체의 의학적 정확성은 BCSS 원본 주석(병리학자 제작)을 신뢰하는 것이며, 비전문가 육안으로 검증한 범위는 "전처리 과정에서 라벨이 안 망가졌는가"까지임

**결론: 전처리 파이프라인 기술적 검증 완료.**

### TIL 비율 분포 관문 (기획서 Step 5) — 통과 ✅

`til_ratio_analysis.py`로 151명 GT 마스크에서 sTIL 비율(공식: `immune / (immune + stroma) × 100%`,
국제 TIL 워킹그룹 정의) 계산. (2026-07-14 수정된 클래스 매핑·공식 기준 최종 재실행 결과)

| 항목 | 값 |
|------|:---:|
| 최소 / 최대 | 0.0% / 88.6% |
| 평균 / 중앙값 / 표준편차 | 24.9% / 21.8% / 20.9% |
| 컷오프 미만 (<50%, non-LPBC) | 130명 |
| 컷오프 이상 (≥50%, LPBC) | 21명 |
| **컷오프 근처(40~60%, 기권 로직 대상군)** | **30명** |
| 분모(immune+stroma)=0이라 계산 불가 | 0장 |

**판정: ✅ 통과.** 컷오프 근처에 30명이 실제로 존재해서, 기획서의 핵심 아이디어(경계 케이스만 병리의에게 기권)가 이 데이터에서 의미 있게 작동할 근거가 확인됨. 전체 환자 TIL 10% 미만(전제 붕괴 조건)도 아님 — 43명(28%)만 0~10% 구간. 공식 수정(immune/(immune+stroma))으로 값이 0~100% 범위 내로 정상적으로 제한됨을 확인 (이전 잘못된 공식(immune/stroma)에서는 100% 초과 사례가 있었음).

상세 결과: `preprocessed/til_ratio_analysis.csv` (환자별 TIL 비율 전체)
